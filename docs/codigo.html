2. Poner a funcionar el servidor

  1. Instala Python 3.12En Windows, marca "Add python.exe to PATH" en el instalador.
  2. Instala el driver USB del ESP32CP210x (Silicon Labs) o CH340 (WCH), según el chip junto al conector.
  3. Conecta el ESP32 y la cámaraCon un cable USB de datos.
  4. ArrancaDoble clic en servidor_web/arrancar_servidor.bat, o desde la terminal: 
    cd servidor_web
python -m pip install -r requirements.txt
python app.py
  5. Abre la páginahttp://localhost:5000. Desde el celular, usa la IP que muestra la terminal, en la misma red WiFi.
Sin brazoSi no hay ESP32 conectado, el servidor usa un ESP32 simulado: la página funciona igual, para pruebas.

3. Subir el firmware

  1. Cierra el servidorEl puerto USB debe estar libre.
  2. Abre firmware_esp32 en VS Code con PlatformIODescarga la plataforma y la librería la primera vez (necesita internet).
  3. Build y UploadSi se queda en "Connecting...", mantén presionado el botón BOOT del ESP32.
  4. VerificaEn el monitor serie a 115200 debe aparecer LISTO v2.

Una subida normal conserva los límites y el HOME guardados en la memoria del ESP32.

4. Protocolo serie (115200 baudios)

Una orden por línea. Puedes probarlo a mano en el monitor serie, con el servidor cerrado.

Laptop → ESP32Acción
J<i> <g>Mover la articulación i (0 a 5) a g grados
H · HGIr a HOME · guardar posición actual como HOME
SSTOP: congela sin soltar los servos y apaga la banda
V <p>Velocidad general en % (10 a 100)
X <0|1>Modo calibración (0° a 180°, velocidad ≤ 25 %)
L<i> <min> <max>Nuevos límites de la articulación i
RRestaurar límites y HOME de fábrica
B <-100..100> · B?Potencia de la banda con signo · consultar
? · CPedir objetivos y posición · pedir configuración
ESP32 → LaptopSignificado
LISTO v2 cfg=...Arranque (memoria o fabrica)
P o0 … o5Objetivos de cada articulación
A a0 … a5 mPosición actual (m = 1 si se mueve), 20 veces por segundo
C n0 x0 h0 …Mínimo, máximo y HOME de cada articulación
B p · B NAEstado de la banda · banda no disponible
E textoError
J0 120     # base a 120°
H          # volver a HOME
B 40       # banda adelante al 40 %
S          # STOP
